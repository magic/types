@magic/types

comprehensive and thoroughly tested type comparison library

install

npm install @magic/types

import

import single function

// single function importimport { isArray } from '@magic/types'isArray([]) // true

import all functions

import is from '@magic/types'is.array([]) // true

functions

@magic/types exports an object of functions to typecheck.

is

test a value for multiple types

is.is(ele, ...types)is.is('astring', 'string', 'object') // trueis.is(42, 'string', 'object') // false

not

test if a value is not of a type

not(ele, ...types)not('astring', 'string', 'object') // falsenot(42, 'string', 'object') // true

alias is.neq, isNeq, isNot

not (and is.not) is also a namespace with negated versions of every check:

is.not.array([]) // falseis.not.len.eq('abc', 'def') // falseis.not.case.upper('lowercase') // trueis.not.deep.eq([1], [1]) // falseis.not.ip.v4('192.168.1.1') // false

length

compare the lengths of two values. all of these can also be curried.

is.eq('abc', 'def') // trueis.gt('abcd', 'ab') // trueis.gt('abcd')('ab') // trueis.gte('abc', 'ab') // trueis.lt('ab', 'abc') // trueis.lte('abc', 'abc'// true

aliases is.equal, is.greater, is.bigger, is.greaterequal, is.biggerequal, is.gteq, is.lower, is.smaller, is.lowerequal, is.smallerequal, is.lteq

also exported: isLengthEqual, isLengthGreater, isLengthGreaterOrEqual, isLengthSmaller, isLengthSmallerOrEqual, compareCount
